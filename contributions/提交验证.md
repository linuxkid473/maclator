```sh
clang -arch arm64 -O2 -pthread \
  tests/guest/signals_async.c tests/guest/signals_registers.S \
  -o /tmp/maclator-signals-arm64
codesign -f -s - /tmp/maclator-signals-arm64
python3 tests/check_guest_signals.py \
  --runtime target/release/maclator --guest /tmp/maclator-signals-arm64 \
  --sysroot "$ARM_SYSROOT" --output /tmp/maclator-signals-result --deadline 5
```

`ARM_SYSROOT` 由测试者设置为自己的 sysroot。子进程架构路由测试使用 `tests/check_spawn_formats.py` 的 `--runtime`、`--sysroot`、`--output` 参数。

## JIT 状态与实验开关

下列 15 个独立进程均返回成功，解析到的 mismatch 均为零。它们使用上面的同一份新 binary，未把静态发射计数当作动态执行次数。

| 类别 | 重新验证范围 |
| --- | --- |
| budgetflags | 60 个状态检查点，缺失 dead-flag 覆盖为零 |
| branchcache | 1,200 个原生案例 |
| FMA | 32,768 个边界案例 + 2,000 个随机案例 |
| operandcache | 4,000 个 block |
| fp-modes | 32,768 个边界案例 + 2,000 个随机案例 |
| loopcache | 1,284 个案例，另有 48 个成对访问案例 |
| cselchain | 3,072 个固定案例 + 2,000 个随机案例，包含 fallback |
| effectiveaddress | 开关各运行一次，每次 29,824 个状态检查点 |
| cachedstore | 开关各运行一次，每次 24,832 个状态检查点 |
| scalarwriteback | 开关各运行一次，每次 25,920 个检查点 |
| gprwriteback | 开关各运行一次，每次 16,648 个检查点，38 次真实链跳转及 6 次公开重入 |

开关验证针对明确的单功能配置；它不能证明全部实验同时开启时兼容或更快。更详细的测试命令和支持范围见 `docs/DEBUGGING.md`。

## 独立组件与历史范围

[独立 NZCV 补丁](experimental/packed-nzcv-upstream/README.md) 另在未经修改的上游基线上验证：开启、关闭各 6,328 个确定性原生案例，以及两种模式的五类随机 JIT 测试，均零 mismatch。其 AOT 版本为 16；主提交目录为 AOT22，两者的用途和应用基线分别说明。

独立原型的补丁应用检查、源文件构建或数据解析检查，只证明其各自列出的范围；GPU 屏幕呈现、精确同步 fault 恢复、AOT+VERIFY 一般兼容，以及 95% 原生性能目标仍有未完成事项。
